# Estimation Methodology - Cafeteria Pre-Order App

## 1. Estimation Scale
Our team uses the modified **Fibonacci sequence** for story points: `1, 2, 3, 5, 8, 13`.
- **1–2 points:** Low complexity tasks, simple status toggles, minor UI tweaks.
- **3–5 points:** Medium-to-high complexity features requiring frontend components, database routing, and business rule validation (e.g., slot capacity constraints).

## 2. Baseline Reference Story
- **Baseline Story:** *US1: View Menu and Item Availability* was chosen as our reference **3-point** story to set the benchmark for database queries and UI rendering.

## 3. Backlog Points Summary
- **Total User Stories:** 16 stories
- **Core MVP Points:** 35 points (Stories US1 through US3, US5 through US7, US9 through US11, US13 through US15)
- **Stretch Goals Points:** 15 points (Stories US4, US8, US12, US16)
